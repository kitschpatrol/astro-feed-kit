This is the French homepage. The body stays in English so the playground stays
easy to read; what matters is that it lives in `src/content/docs/fr/`.

## Feeds

- [/fr/rss.xml](/fr/rss.xml)
- [/fr/atom.xml](/fr/atom.xml)
- [/fr/feed.json](/fr/feed.json)

## Entries

Only entries in the `fr/` folder reach these feeds. "English only" is served
here as Starlight fallback content, but it is left out of the French feed.

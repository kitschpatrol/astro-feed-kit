The French counterpart of "Hello, feed-kit". It lives in the `fr/` folder, so it
appears in `/fr/rss.xml` and links to `/fr/hello-feed-kit/`. The body stays in
English so the playground stays easy to read.

## Headings render through

A second-level heading and some **bold** text confirm the markdown renderer
path runs end-to-end before the feed is serialized.

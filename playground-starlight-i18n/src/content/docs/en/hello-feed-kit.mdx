This is a short MDX entry used to exercise `astro-feed-kit`'s default resolver
chain inside a multilingual Starlight docs collection. It lives in the `en/`
folder, so it appears in `/en/rss.xml` and links to `/en/hello-feed-kit/`.

## Headings render through

A second-level heading and some **bold** text confirm the markdown renderer
path runs end-to-end before the feed is serialized.

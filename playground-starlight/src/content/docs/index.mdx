This Starlight playground demonstrates `astro-feed-kit` generating feeds from a
docs collection.

## Feeds

- [/rss.xml](/rss.xml)
- [/atom.xml](/atom.xml)
- [/feed.json](/feed.json)

## Entries

The sidebar lists each demo entry. Their dated frontmatter is what makes them
eligible for the feed (see the `filter` in `astro.config.ts`).
